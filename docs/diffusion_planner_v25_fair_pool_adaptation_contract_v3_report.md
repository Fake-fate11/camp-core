# V25 Fair-Pool Adaptation Contract v3 Fail-Closed Executability Report

## Outcome and scope

The versioned
`camp_dp_v25_fair_pool_adaptation_contract_v3` and its separate-role
independent literal review are sealed and PASS. This package closes the three
pre-acquisition contract gaps identified in the v2 incremental audit:

1. caller-provided manifests, B4 clone inventories, and arbitrary contract
   roots can no longer self-authorize a preflight receipt;
2. source scenes are generated by one deterministic, outcome-free,
   source-bound materializer rather than supplied as free-form records; and
3. qualification results are keyed by phase, mode, and endpoint and are
   derived from numeric and typed hard evidence without a caller-supplied
   within-mode boolean or status.

This remains a design-only package. Acquisition, actual 128-manifest
materialization, calibration, model repeats, pools, selectors, closed-loop
execution, Fresh, holdout, training, retraining, claim, promotion, and
deployment are not authorized and all associated run counts remain zero.

The scope is machine-limited to one `four_track_highway` map, one ordered
route, four density tiers, 64 development-calibration states, and 64
independent-validation states. A future PASS would mean only that evidence in
this bounded single-route scope did not trigger retraining. It would not prove
general architecture equivalence, OOD coverage, benefit, or safety.

## Phase-aware endpoint and decision topology

The 37 semantic endpoints are preserved, including their v2 formula, units,
shape, applicability, finite/missing rule, resolution floor, and pair
topology. Each v3 registry row carries an independently checked SHA of the
complete inherited v2 row.

The qualification vector has 83 exact `(phase, mode, endpoint)` keys:

- `sequential_within / sequential_batch1_x8`;
- `batch8_within / single_invocation_batch8`;
- `cross_mode / matched_repeat_cross_mode`; and
- one global split-preflight key.

Atoms, ego/neighbor trajectory errors, and absolute Static/Scene score errors
are evaluated within both modes and cross-mode. Cross-normalized score delta,
margin ratio, rank error, and neighbor relative inflation are cross-only and
are forbidden in either within-mode keyset. This removes the v2 circular
dependency.

Every numeric receipt contains 64 ordered validation state IDs and values,
the exact threshold, and a threshold-authority SHA. Missing/nonfinite values
block without complete-case shrinkage. Equality does not exceed the
threshold. The frozen Clopper-Pearson rule remains `k<=2` and one-sided 95%
upper `<=0.10`.

Typed hard evidence independently derives:

- exact fixed-DP/checkpoint/model/decoder/encoder/map/route/generator
  fingerprint equality per mode;
- 64-state finite and eight-unique-row K8 validity per mode;
- immutable pool tensor and zero post-pool DP/model/latent/generation calls;
- Static and Scene length-8 mask equality;
- Static and Scene selected-index/action behavior from both 80x4 finite
  action arrays and executable/terminal enums; and
- split-preflight authority/root/receipt equality.

The public decision function accepts only `(contract, receipt)`. It has no
`both_within_modes_pass` or status parameter. It derives the two within-mode
PASS values from required evidence, enters cross-mode only when both pass,
and applies the frozen precedence:

1. authority failure;
2. evidence missing;
3. within-mode generator instability;
4. cross-mode functional drift; and
5. bounded-scope PASS.

There is no weighted total, benefit claim, retraining conclusion, or general
equivalence claim.
