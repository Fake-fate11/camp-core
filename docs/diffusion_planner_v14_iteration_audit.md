## Current V14 Public Simulator Source Reclassification Unblocked Candidate Tensor Preflight After 88fd3ca

The previous EOF remains valid only for the narrow TIER IV DP training-source
question: AutoDL does not currently contain a nonfixture TIER IV DP training
source `.npz`, Autoware rosbag metadata, `.db3`, `.mcap`, or C++ training binary
source that can reproduce TIER IV's official rosbag-to-DP-`.npz` training-data
path. NuScenes is present.

AutoDL does expose public nuScenes archives under `/autodl-pub/data/nuScenes`.
Those archives are a real available data source, but they are not currently
extracted into CAMP data paths, converted to DP-native records, or part of the
official TIER IV rosbag-to-DP-`.npz` converter path. A nuScenes-to-DP adapter
would be a separate data-adapter gate and is not authorized by this EOF.

The current objective is not to train or modify Diffusion Planner. CAMP must
only rerank/select fixed candidate tensors generated by the unmodified fixed
TIER IV DP checkpoint. TIER IV's public guidance provides the correct public
route for that objective: use the official v5.0 DP weights and parameter file
with public Autoware planning-simulator maps and declared routes. The official
TIER IV answer states that published DP weights used internal data and points
to the rosbag converter for DP training data; the Autoware planning-simulation
docs provide the public sample map, model-artifact workflow, simulator launch,
and Nishishinjuku lane-change map/scenario flow.

Therefore the external DP-native source `.npz` manifest gate is reclassified
as too strict for CAMP fixed-DP candidate tensor training. The new next gate is
a preflight for public simulator fixed-DP candidate generation. No candidate
generation, CAMP training, DP modification, promotion, deployment, online
selector change, or safety-benefit claim was executed by this reclassification.

Remote evidence was collected on AutoDL after local and `origin/main` were both
at `88fd3cac6722aedfd4ca13b41f904b4a3331c219`. AutoDL CAMP matched
`origin/main` with unrelated untracked files only. AutoDL DP remained fixed at
`7a1d33da277a1992ec474b5383a0c963c72e04e4`.
