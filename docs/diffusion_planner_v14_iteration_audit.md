## Current V14 Source Data Availability Audit Rejected Missing Raw DP Source After 6f5bf60

Executed the current v14 next-work target by checking whether AutoDL has raw
source assets that can produce a valid nonfixture DP-native `.npz` manifest.
Diffusion Planner documents the standard data path as rosbag directories plus
maps through `ros_scripts/parse_rosbag_for_directory.py`, followed by
`diffusion_planner/util_scripts/create_train_set_path.py`. AutoDL currently has
maps and route pickles, but no bag metadata, rosbag `.db3`, `.mcap`, or usable
C++ training binary sources.

DP's `scenario_generation.replay` can dump per-step observation NPZs, but those
are closed-loop replay observations and remain disallowed as CAMP training or
online input under the current boundary. Synthetic static source generation is
also not authorized by the current EOF. No fixed DP candidate generation, CAMP
